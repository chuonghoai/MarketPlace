# SmartSpace

## Prerequisites

- Node.js
- npm
- Flutter
- Java
- Maven

> Note: npm chỉ được sử dụng làm task runner ở root monorepo. npm không thay thế Flutter hoặc Maven.

## Development Commands

Root `package.json` được sử dụng làm command runner cho monorepo.

### Chạy Development

- **Chạy Backend:**
  ```bash
  npm run backend:dev
  ```

- **Chạy Web:**
  ```bash
  npm run web:dev
  ```
