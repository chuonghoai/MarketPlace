## 2. Tính số lượng đường thi hành độc lập (Cyclomatic Complexity)

Theo phương pháp phân tích kiểm thử dòng điều khiển (Basis Path Testing của Thomas McCabe):
- **Số nút điều kiện (Predicate Nodes):** $P = 45$ (mỗi node đều có 2 nhánh rẽ True/False).
- **Độ phức tạp Cyclomatic $V(G)$ tính theo nút vị từ:**
  $$V(G) = P + 1 = 45 + 1 = 46$$
- **Độ phức tạp Cyclomatic $V(G)$ tính theo đồ thị luồng điều khiển CFG:**
  - Tổng số node: $N = 148$ (gồm 146 node đánh số trong mã nguồn + node start + node Exit).
  - Tổng số cạnh: $E = 192$.
  $$V(G) = E - N + 2 = 192 - 148 + 2 = 46$$

Như vậy, tập cơ sở của chức năng checkoutOrder gồm đúng **46 đường thi hành tuyến độc lập (46 Basis Paths)**, tương ứng với **46 Test Cases** bao phủ 100% các nhánh rẽ và câu lệnh.
